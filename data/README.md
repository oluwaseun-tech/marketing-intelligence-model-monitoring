# Data

All project records are synthetic and created for portfolio demonstration.

- `raw/`: generated advertising, sales and promotions source data.
- `processed/`: audited and remediated advertising data.
- `outputs/`: channel-level metrics, model inputs, predictions, contribution estimates, Bayesian coefficient summaries and monitoring reports.

Revenue is business-level weekly revenue. It is not channel-attributed revenue; therefore, channel ROAS should not be inferred from these files. See the root README for definitions and modelling limitations.
