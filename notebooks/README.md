# Notebooks

The five Jupyter notebooks are packaged in [notebook_source_bundle.zip](notebook_source_bundle.zip). Download and extract the ZIP into this folder; it contains the notebooks in execution order:

1. `01_data_generation.ipynb`
2. `02_data_quality_audit.ipynb`
3. `03_marketing_analytics.ipynb`
4. `04_bayesian_mmm.ipynb`
5. `05_marketing_model_monitoring.ipynb`

The bundle removes saved cell outputs and personal Colab execution metadata while preserving notebook cell content. The notebooks were authored in Google Colab and initially use a Google Drive project path. Update setup/path cells when running elsewhere.
