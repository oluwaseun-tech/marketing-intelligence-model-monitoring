# Notebooks

Run the five Jupyter notebooks in numerical order. They were authored in Google Colab and initially used a Google Drive project path. Update the setup/path cells when running in another environment.

1. `01_data_generation.ipynb`
2. `02_data_quality_audit.ipynb`
3. `03_marketing_analytics.ipynb`
4. `04_bayesian_mmm.ipynb`
5. `05_marketing_model_monitoring.ipynb`

The Bayesian MMM is an illustrative regression workflow on synthetic data; its adstock and saturation settings are assumptions rather than calibrated causal effects.
